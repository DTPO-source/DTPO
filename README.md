# DTPO

**Digital Twin for 5G AI-RAN: Sim-to-Real Gap Measurement and Optimization**

This repository hosts the DTPO project webpage. The page follows the academic
project-page structure used by Mobiman and includes a real-world 100 MHz channel
measurement demo; the remaining media positions are reserved for future results.

Open `index.html` directly in a browser to preview the webpage.

## Repository Structure

```text
.
├── index.html          # DTPO project webpage
├── assets/
│   ├── images/         # Figures, diagrams, and result images
│   └── videos/         # Platform and evaluation demo videos
└── source/             # DTPO source code and scripts
```
